# Docusaurus files

This directory contains the minimal Docusaurus run environment for the LearnGLES repository.

Files added:

- package.json — scripts and dependencies
- docusaurus.config.js — site configuration
- sidebars.js — docs sidebar
- docs/intro.md — starter doc
- src/css/custom.css — minimal styling
- static/img/logo.svg — placeholder logo

Run locally: `npm install` then `npm start`.
