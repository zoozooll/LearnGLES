# Learn OpenGL ES 3.0+ for Android

Welcome to LearnGLES! This is a comprehensive tutorial series for learning OpenGL ES 3.0+ on Android, covering fundamental concepts to advanced rendering techniques.

## 🎯 What You'll Learn

- **Basic Techniques**: Shaders, textures, transformations, and fundamental OpenGL concepts
- **Lighting & Post-Processing**: Phong lighting, shadow mapping, HDR, bloom, and SSAO
- **Physically Based Rendering**: PBR theory, material properties, and image-based lighting
- **Advanced Techniques**: Cascaded shadow maps, order-independent transparency, and direct state access

## 🚀 Getting Started

1. Clone the repository from [GitHub](https://github.com/minininja/LearnGLES)
2. Open the project in Android Studio
3. Build and run on an Android device or emulator
4. Follow the tutorials in order from Basic Techniques → Advanced

## 📚 Tutorial Structure

The tutorials are organized in a logical progression:

### 🏗️ Basic Techniques
Start with the fundamentals of OpenGL ES, including shaders, textures, and basic rendering techniques.

### 💡 Lighting & Post-Processing
Learn about lighting models, shadow mapping, and advanced post-processing effects.

### ✨ Physically Based Rendering
Master PBR concepts for realistic material rendering.

### 🎨 Advanced Techniques
Explore advanced rendering techniques for professional-quality graphics.

## 🔧 Requirements

- Android Studio 4.0+
- Android SDK 26+
- OpenGL ES 3.0+ compatible device
