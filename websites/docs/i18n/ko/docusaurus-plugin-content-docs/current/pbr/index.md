# PBR 기술

물리 기반 렌더링（PBR）튜토리얼은 현재 게임과 영화에서 사용되는 고급 렌더링 기술을 다룹니다.

## 🎯 학습 목표

- 물리 기반 렌더링 원리 이해
- 이미지 기반 조명（IBL）구현
- 텍스처를 사용한 재질 속성 제어
- 패럴랙스 및 변위 매핑 구현
- 환경 오클루전 구현

## 📚 튜토리얼 목록

| 튜토리얼 | 설명 |
|----------|-------------|
| [Normal Mapping](/docs/pbr/normal-mapping) | 폴리곤을 늘리지 않고 표면 세부 정보 추가 |
| [Parallax Mapping](/docs/pbr/parallax-mapping) | 텍스처 깊이 시뮬레이션 |
| [PBR Theory](/docs/pbr/pbr-theory) | Cook-Torrance BRDF 구현 |
| [PBR Textures](/docs/pbr/pbr-textures) | PBR 텍스처 맵 사용 |
| [IBL](/docs/pbr/ibl) | HDR 맵을 사용한 이미지 기반 조명 |
