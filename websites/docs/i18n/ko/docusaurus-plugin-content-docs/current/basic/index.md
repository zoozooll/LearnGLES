# 기본 기술

기본 기술 튜토리얼은 보다 고급 주제로 넘어가기 전에 이해해야 할 기본 개념을 다룹니다.

## 📋 전제 조건

이 튜토리얼을 시작하기 전에 다음이 필요합니다.

- C++와 Kotlin 기초 지식
- 선형 대수(벡터, 행렬) 이해
- Android 개발에 대한 익숙함

## 🎯 학습 목표

이 튜토리얼을 완료하면 다음을 할 수 있습니다.

- GLSL 셰이더 작성 및 컴파일
- 3D 모델에 텍스처 로드 및 적용
- 기본 변환 구현(이동, 회전, 스케일링)
- 투명도 및 깊이 테스트 처리
- Assimp를 사용하여 복잡한 3D 모델 로드
- 스켈레탈 애니메이션 구현
