# 조명 기술

조명 튜토리얼은 현실적인 빛과 그림자 효과를 구현하기 위한 필수 기술을 다룹니다.

## 🎯 학습 목표

- Phong 및 Blinn-Phong 조명 모델 구현
- 다중 광원 처리
- 소프트 셰도우와 하드 셰도우 구현
- HDR 렌더링 및 노출 제어 구현
- 후처리 효과 적용
