# 고급 기술

고급 기술 튜토리얼은 모바일 플랫폼을 위한 고급 렌더링 기술을 다룹니다.

## 🎯 학습 목표

- 계단식 그림자 맵（CSM）구현
- 투명 객체의 정확한 렌더링（OIT）처리
- 직접 상태 접근（DSA）사용
- 지연 셰이딩 구현
- 모바일 렌더링 성능 최적화

## 📚 튜토리얼 목록

| 튜토리얼 | 설명 |
|----------|-------------|
| [CSM](/docs/advanced/csm) | 고품질 그림자를 위한 계단식 그림자 맵 |
| [OIT](/docs/advanced/oit) | 순서 무관 투명성 |
| [DSA](/docs/advanced/dsa) | 직접 상태 접근 |
