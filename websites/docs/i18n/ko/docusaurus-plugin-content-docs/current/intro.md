# LearnGLES에 오신 것을 환영합니다

LearnGLES는 기본 렌더링부터 고급 물리 기반 렌더링(PBR) 및 후처리 효과에 이르기까지 다양한 **OpenGL ES 3.0+** 기술을 시연하는 Android 애플리케이션입니다.

## 🎯 배울 내용

이 튜토리얼 시리즈는 모바일 그래픽스 프로그래밍 전문가가 되기 위해 알아야 할 모든 것을 다룹니다:

- **기본 기술**: 셰이더, 텍스처, 변환 및 렌더링 기초
- **조명**: Phong/Blinn-Phong 모델, 그림자, HDR 및 후처리
- **PBR**: IBL, 노멀/패럴랙스 매핑을 사용한 물리 기반 렌더링
- **고급**: CSM, OIT, DSA 및 기타 최신 기술

## 🛠️ 기술 스택

- **플랫폼**: Android
- **언어**: Kotlin (UI), C++ (렌더링)
- **UI 프레임워크**: Jetpack Compose
- **그래픽스 API**: OpenGL ES 3.0+
- **핵심 라이브러리**: Assimp, GLM, stb_image, FreeType

## 📚 시작하기

1. 리포지토리 클론: `git clone https://github.com/minininja/LearnGLES.git`
2. Android Studio (Ladybug 이상)에서 프로젝트 열기
3. NDK와 CMake가 설치되어 있는지 확인
4. GLES 3.0 지원 기기 또는 에뮬레이터에서 빌드 및 실행

## 📖 튜토리얼 구조

각 튜토리얼에는 다음이 포함됩니다:

- **개념 설명**: 기술이 무엇인지 및 왜 중요한지
- **수학적 배경**: 핵심 공식 및 이론
- **코드 설명**: 단계별 구현
- **인터랙티브 데모**: 앱에서 시도해보기
