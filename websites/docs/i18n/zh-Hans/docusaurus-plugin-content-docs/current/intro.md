# 欢迎来到 LearnGLES

LearnGLES 是一个 Android 应用程序，展示了各种 **OpenGL ES 3.0+** 技术，从基本渲染到高级基于物理的渲染 (PBR) 和后处理效果。

## 🎯 你将学到什么

本教程系列涵盖了你成为移动图形编程专家所需了解的一切：

- **基础技术**：着色器、纹理、变换和渲染基础
- **光照**：Phong/Blinn-Phong 模型、阴影、HDR 和后处理
- **PBR**：基于物理的渲染，包括 IBL、法线/视差贴图
- **高级**：CSM、OIT、DSA 和其他现代技术

## 🛠️ 技术栈

- **平台**：Android
- **语言**：Kotlin (UI)、C++ (渲染)
- **UI 框架**：Jetpack Compose
- **图形 API**：OpenGL ES 3.0+
- **关键库**：Assimp、GLM、stb_image、FreeType

## 📚 开始学习

1. 克隆仓库：`git clone https://github.com/minininja/LearnGLES.git`
2. 在 Android Studio (Ladybug 或更新版本) 中打开项目
3. 确保安装了 NDK 和 CMake
4. 在支持 GLES 3.0 的设备或模拟器上构建并运行

## 📖 教程结构

每个教程包括：

- **概念解释**：技术是什么以及为什么重要
- **数学背景**：关键公式和理论
- **代码演练**：分步实现
- **交互式演示**：在应用中尝试
