# 基于物理的渲染

PBR 教程涵盖了现代渲染技术，通过模拟光和材料的物理特性来产生逼真的结果。

## 📋 前提条件

- 完成基础技术教程
- 完成光照教程
- 理解 BRDF 和材料属性

## 🎯 学习目标

完成这些教程后，你将能够：

- 实现 Cook-Torrance BRDF
- 使用 PBR 纹理贴图（albedo、normal、metallic、roughness、AO）
- 实现基于图像的光照 (IBL)
- 使用法线和视差贴图添加表面细节
