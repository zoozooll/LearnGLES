# 学习 Android 平台的 OpenGL ES 3.0+

欢迎来到 LearnGLES！这是一套全面的 OpenGL ES 3.0+ Android 教程系列，涵盖从基础概念到高级渲染技术。

## 🎯 你将学到什么

- **基础技术**：着色器、纹理、变换和 OpenGL 基本概念
- **光照与后处理**：Phong 光照、阴影映射、HDR、Bloom 和 SSAO
- **基于物理的渲染**：PBR 理论、材质属性和基于图像的光照
- **高级技术**：级联阴影贴图、顺序无关透明度和直接状态访问

## 🚀 开始学习

1. 从 [GitHub](https://github.com/minininja/LearnGLES) 克隆仓库
2. 在 Android Studio 中打开项目
3. 在 Android 设备或模拟器上构建并运行
4. 按顺序学习教程：基础技术 → 高级技术

## 📚 教程结构

教程按照逻辑顺序组织：

### 🏗️ 基础技术
从 OpenGL ES 的基础知识开始，包括着色器、纹理和基本渲染技术。

### 💡 光照与后处理
学习光照模型、阴影映射和高级后处理效果。

### ✨ 基于物理的渲染
掌握 PBR 概念，实现逼真的材质渲染。

### 🎨 高级技术
探索专业级图形的高级渲染技术。

## 🔧 系统要求

- Android Studio 4.0+
- Android SDK 26+
- 支持 OpenGL ES 3.0+ 的设备
