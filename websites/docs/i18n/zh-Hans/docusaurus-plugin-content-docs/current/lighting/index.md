# 光照与后处理

光照与后处理教程涵盖使你的 3D 场景看起来更逼真和视觉吸引力的技术。

## 📋 前提条件

- 完成基础技术教程
- 理解向量数学和点积

## 🎯 学习目标

完成这些教程后，你将能够：

- 实现 Phong 和 Blinn-Phong 光照模型
- 处理多种光源类型（方向光、点光、聚光灯）
- 生成实时阴影
- 实现 HDR 渲染和伽马校正
- 添加后处理效果如 Bloom 和 SSAO
