# 基础技术

基础技术教程涵盖了你在深入更高级主题之前需要理解的基本概念。

## 📋 前提条件

开始这些教程之前，你应该具备：

- C++ 和 Kotlin 的基础知识
- 线性代数（向量、矩阵）的理解
- Android 开发的熟悉度

## 🎯 学习目标

完成这些教程后，你将能够：

- 编写和编译 GLSL 着色器
- 加载并应用纹理到 3D 模型
- 实现基本变换（平移、旋转、缩放）
- 处理透明度和深度测试
- 使用 Assimp 加载复杂的 3D 模型
- 实现骨骼动画
