# 高级技术

高级技术教程涵盖了解决复杂问题和提高性能的前沿渲染技术。

## 📋 前提条件

- 完成所有先前的教程
- 对 OpenGL ES 概念有深刻理解

## 🎯 学习目标

完成这些教程后，你将能够：

- 为大型场景实现级联阴影贴图
- 使用 OIT 正确渲染透明对象
- 使用直接状态访问提高性能
