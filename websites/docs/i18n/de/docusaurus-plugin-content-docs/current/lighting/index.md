# Beleuchtungstechniken

Die Beleuchtung-Tutorials decken die Kerntechniken für realistische Licht- und Schatteneffekte ab.

## 🎯 Lernziele

- Phong- und Blinn-Phong-Beleuchtungsmodelle implementieren
- Mehrere Lichtquellen verarbeiten
- Weiche und harte Schatten implementieren
- HDR-Rendering und Belichtungskontrolle implementieren
- Post-Processing-Effekte anwenden
