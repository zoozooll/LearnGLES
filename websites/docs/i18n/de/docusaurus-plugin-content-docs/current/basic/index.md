# Grundlagen

Die Grundlagen-Tutorials decken die fundamentalen Konzepte ab, die du verstehen musst, bevor du zu fortgeschritteneren Themen übergehst.

## 📋 Voraussetzungen

Bevor du mit diesen Tutorials beginnst, solltest du haben:

- Grundkenntnisse in C++ und Kotlin
- Verständnis von Linearer Algebra (Vektoren, Matrizen)
- Vertrautheit mit Android-Entwicklung

## 🎯 Lernziele

Nach Abschluss dieser Tutorials kannst du:

- GLSL-Shader schreiben und kompilieren
- Texturen zu 3D-Modellen laden und anwenden
- Grundlegende Transformationen implementieren (Translation, Rotation, Skalierung)
- Transparenz und Tiefentest verarbeiten
- Komplexe 3D-Modelle mit Assimp laden
- Skelettanimationen implementieren
