# Willkommen bei LearnGLES

LearnGLES ist eine Android-Anwendung, die verschiedene **OpenGL ES 3.0+**-Techniken demonstriert, von der Grundlagen-Rendering bis zu fortgeschrittenem physikalisch basiertem Rendering (PBR) und Post-Processing-Effekten.

## 🎯 Was du lernen wirst

Diese Tutorial-Reihe deckt alles ab, was du wissen musst, um ein Profi im mobilen Grafik-Programmierung zu werden:

- **Grundlagen**: Shader, Texturen, Transformationen und Rendering-Grundlagen
- **Beleuchtung**: Phong/Blinn-Phong-Modelle, Schatten, HDR und Post-Processing
- **PBR**: Physikalisch basiertes Rendering mit IBL, Normal-/Parallax-Mapping
- **Fortgeschritten**: CSM, OIT, DSA und andere moderne Techniken

## 🛠️ Tech Stack

- **Plattform**: Android
- **Sprache**: Kotlin (UI), C++ (Rendering)
- **UI-Framework**: Jetpack Compose
- **Grafik-API**: OpenGL ES 3.0+
- **Schlüsselbibliotheken**: Assimp, GLM, stb_image, FreeType

## 📚 Loslegen

1. Repository klonen: `git clone https://github.com/minininja/LearnGLES.git`
2. Projekt in Android Studio (Ladybug oder neuer) öffnen
3. Sicherstellen, dass NDK und CMake installiert sind
4. Auf einem Gerät oder Emulator mit GLES 3.0-Unterstützung bauen und ausführen

## 📖 Tutorial-Struktur

Jedes Tutorial umfasst:

- **Konzept-Erklärung**: Was die Technik ist und warum sie wichtig ist
- **Mathematischer Hintergrund**: Schlüsselformeln und Theorie
- **Code-Walkthrough**: Schritt-für-Schritt-Implementierung
- **Interaktive Demo**: Ausprobieren in der App
