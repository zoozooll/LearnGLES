# OpenGL ES 3.0+ für Android lernen

Willkommen bei LearnGLES! Dies ist eine umfassende Tutorial-Reihe zum Erlernen von OpenGL ES 3.0+ auf Android, die von Grundlagen bis zu fortgeschrittenen Rendering-Techniken reicht.

## 🎯 Was du lernen wirst

- **Grundlagen**: Shader, Texturen, Transformationen und grundlegende OpenGL-Konzepte
- **Beleuchtung & Post-Processing**: Phong-Beleuchtung, Schattenmapping, HDR, Bloom und SSAO
- **Physikalisch basiertes Rendering**: PBR-Theorie, Materialeigenschaften und Bildbasierte Beleuchtung
- **Fortgeschrittene Techniken**: Kaskadierte Schattenkarten, ordnungsunabhängige Transparenz und Direct State Access

## 🚀 Loslegen

1. Repository von [GitHub](https://github.com/minininja/LearnGLES) klonen
2. Projekt in Android Studio öffnen
3. Auf einem Android-Gerät oder -Emulator bauen und ausführen
4. Tutorials in der Reihenfolge von Grundlagen → Fortgeschritten durcharbeiten

## 📚 Tutorial-Struktur

Die Tutorials sind logisch gegliedert:

### 🏗️ Grundlagen
Beginne mit den Grundlagen von OpenGL ES, einschließlich Shadern, Texturen und grundlegenden Rendering-Techniken.

### 💡 Beleuchtung & Post-Processing
Lerne über Beleuchtungsmodelle, Schattenmapping und fortgeschrittene Post-Processing-Effekte.

### ✨ Physikalisch basiertes Rendering
Meistere PBR-Konzepte für realistische Materialdarstellung.

### 🎨 Fortgeschrittene Techniken
Erkunde fortgeschrittene Rendering-Techniken für professionelle Grafiken.

## 🔧 Anforderungen

- Android Studio 4.0+
- Android SDK 26+
- Gerät mit OpenGL ES 3.0+ Unterstützung
