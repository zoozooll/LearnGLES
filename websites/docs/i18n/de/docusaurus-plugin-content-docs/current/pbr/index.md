# PBR-Techniken

Die physikalisch basierte Rendering (PBR)-Tutorials decken fortschrittliche Rendering-Techniken ab, die heute in Spielen und Filmen verwendet werden.

## 🎯 Lernziele

- Prinzipien des physikalisch basierten Renderings verstehen
- Image-Based Lighting (IBL) implementieren
- Materialeigenschaften mit Texturen steuern
- Parallax- und Displacement-Mapping implementieren
- Ambient Occlusion implementieren
