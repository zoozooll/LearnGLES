# Bem-vindo ao LearnGLES

LearnGLES é um aplicativo Android que demonstra diversas técnicas **OpenGL ES 3.0+**, desde renderização básica até renderização física avançada (PBR) e efeitos de pós-processamento.

## 🎯 O que você aprenderá

Esta série de tutoriais cobre tudo o que você precisa saber para se tornar um especialista em programação de gráficos móveis:

- **Técnicas Básicas**: Shaders, texturas, transformações e fundamentos de renderização
- **Iluminação**: Modelos Phong/Blinn-Phong, sombras, HDR e pós-processamento
- **PBR**: Renderização física com IBL, mapeamento normal/parallax
- **Avançado**: CSM, OIT, DSA e outras técnicas modernas

## 🛠️ Pilha de Tecnologias

- **Plataforma**: Android
- **Linguagem**: Kotlin (UI), C++ (Renderização)
- **Framework UI**: Jetpack Compose
- **API de Gráficos**: OpenGL ES 3.0+
- **Bibliotecas Chave**: Assimp, GLM, stb_image, FreeType

## 📚 Começar

1. Clonar o repositório: `git clone https://github.com/minininja/LearnGLES.git`
2. Abrir o projeto no Android Studio (Ladybug ou mais recente)
3. Certificar-se de que NDK e CMake estão instalados
4. Compilar e executar em um dispositivo ou emulador com suporte GLES 3.0

## 📖 Estrutura do Tutorial

Cada tutorial inclui:

- **Explicação do Conceito**: O que é a técnica e por que é importante
- **Fundo Matemático**: Fórmulas chave e teoria
- **Walkthrough de Código**: Implementação passo a passo
- **Demonstração Interativa**: Experimente no aplicativo
