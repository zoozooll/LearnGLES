# Técnicas de Iluminação

Os tutoriais de Iluminação cobrem as técnicas essenciais para implementar efeitos realistas de luz e sombra.

## 🎯 Objetivos de Aprendizado

- Implementar modelos de iluminação Phong e Blinn-Phong
- Manipular múltiplas fontes de luz
- Implementar sombras suaves e duras
- Implementar renderização HDR e controle de exposição
- Aplicar efeitos de pós-processamento
