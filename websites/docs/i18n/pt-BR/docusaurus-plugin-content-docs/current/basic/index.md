# Técnicas Básicas

Os tutoriais de Técnicas Básicas cobrem os conceitos fundamentais que você precisa entender antes de mergulhar em tópicos mais avançados.

## 📋 Pré-requisitos

Antes de começar esses tutoriais, você deve ter:

- Conhecimento básico de C++ e Kotlin
- Compreensão de álgebra linear (vetores, matrizes)
- Familiaridade com desenvolvimento Android

## 🎯 Objetivos de Aprendizado

Após completar esses tutoriais, você poderá:

- Escrever e compilar shaders GLSL
- Carregar e aplicar texturas a modelos 3D
- Implementar transformações básicas (translação, rotação, escala)
- Manipular transparência e teste de profundidade
- Carregar modelos 3D complexos usando Assimp
- Implementar animação esquelética
