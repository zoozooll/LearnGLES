# Aprender OpenGL ES 3.0+ para Android

Bem-vindo ao LearnGLES! Esta é uma série completa de tutoriais para aprender OpenGL ES 3.0+ no Android, cobrindo conceitos fundamentais até técnicas avançadas de renderização.

## 🎯 O que você aprenderá

- **Técnicas Básicas**: Shaders, texturas, transformações e conceitos fundamentais do OpenGL
- **Iluminação e Pós-Processamento**: Iluminação Phong, mapeamento de sombras, HDR, bloom e SSAO
- **Renderização Baseada em Física**: Teoria PBR, propriedades de materiais e iluminação baseada em imagem
- **Técnicas Avançadas**: Mapas de sombra em cascata, transparência independente da ordem e acesso direto ao estado

## 🚀 Começar

1. Clone o repositório do [GitHub](https://github.com/minininja/LearnGLES)
2. Abra o projeto no Android Studio
3. Compile e execute em um dispositivo ou emulador Android
4. Siga os tutoriais na ordem: Técnicas Básicas → Avançadas

## 📚 Estrutura dos Tutoriais

Os tutoriais estão organizados em uma progressão lógica:

### 🏗️ Técnicas Básicas
Comece com os fundamentos do OpenGL ES, incluindo shaders, texturas e técnicas básicas de renderização.

### 💡 Iluminação e Pós-Processamento
Aprenda sobre modelos de iluminação, mapeamento de sombras e efeitos avançados de pós-processamento.

### ✨ Renderização Baseada em Física
Domine os conceitos PBR para renderização realista de materiais.

### 🎨 Técnicas Avançadas
Explore técnicas avançadas de renderização para gráficos de qualidade profissional.

## 🔧 Requisitos

- Android Studio 4.0+
- Android SDK 26+
- Dispositivo compatível com OpenGL ES 3.0+
