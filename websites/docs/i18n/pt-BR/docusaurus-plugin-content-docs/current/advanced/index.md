# Técnicas Avançadas

Os tutoriais de Técnicas Avançadas cobrem técnicas de renderização avançadas para plataformas móveis.

## 🎯 Objetivos de Aprendizado

- Implementar mapas de sombra em cascata (CSM)
- Manipular o renderizado correto de objetos transparentes (OIT)
- Usar acesso direto ao estado (DSA)
- Implementar sombreamento diferido
- Otimizar o desempenho do renderizado móvel
