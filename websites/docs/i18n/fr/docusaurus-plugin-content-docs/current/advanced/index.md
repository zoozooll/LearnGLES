# Techniques Avancées

Les tutoriels de Techniques Avancées couvrent des techniques de rendu avancées pour les plateformes mobiles.

## 🎯 Objectifs d'Apprentissage

- Implémenter les cartes d'ombres en cascade (CSM)
- Gérer le rendu correct des objets transparents (OIT)
- Utiliser l'accès direct à l'état (DSA)
- Implémenter le shading différé
- Optimiser les performances de rendu mobile

## 📚 Liste des Tutoriels

| Tutoriel | Description |
|----------|-------------|
| [CSM](/docs/advanced/csm) | Cartes d'ombres en cascade pour des ombres de haute qualité |
| [OIT](/docs/advanced/oit) | Transparence indépendante de l'ordre |
| [DSA](/docs/advanced/dsa) | Accès direct à l'état |
