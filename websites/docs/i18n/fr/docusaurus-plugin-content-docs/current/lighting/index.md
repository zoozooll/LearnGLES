# Techniques d'Éclairage

Les tutoriels d'Éclairage couvrent les techniques essentielles pour implémenter des effets de lumière et d'ombre réalistes.

## 🎯 Objectifs d'Apprentissage

- Implémenter les modèles d'éclairage Phong et Blinn-Phong
- Gérer plusieurs sources de lumière
- Implémenter des ombres douces et dures
- Implémenter le rendu HDR et le contrôle d'exposition
- Appliquer des effets de post-traitement
