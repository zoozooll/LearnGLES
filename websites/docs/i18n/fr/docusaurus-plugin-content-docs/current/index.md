# Apprendre OpenGL ES 3.0+ pour Android

Bienvenue sur LearnGLES ! Ceci est une série complète de tutoriels pour apprendre OpenGL ES 3.0+ sur Android, couvrant les concepts fondamentaux jusqu'aux techniques avancées de rendu.

## 🎯 Ce que vous apprendrez

- **Techniques de Base** : Shaders, textures, transformations et concepts fondamentaux d'OpenGL
- **Lumière & Post-Traitement** : Lumière Phong, mapping d'ombres, HDR, bloom et SSAO
- **Rendu Physique (PBR)** : Théorie PBR, propriétés des matériaux et illumination basée sur l'image
- **Techniques Avancées** : Cartes d'ombres en cascade, transparence indépendante de l'ordre et accès direct à l'état

## 🚀 Commencer

1. Cloner le dépôt depuis [GitHub](https://github.com/minininja/LearnGLES)
2. Ouvrir le projet dans Android Studio
3. Construire et exécuter sur un appareil ou un émulateur Android
4. Suivre les tutoriels dans l'ordre : Techniques de Base → Avancées

## 📚 Structure des Tutoriels

Les tutoriels sont organisés selon une progression logique :

### 🏗️ Techniques de Base
Commencez par les fondamentaux d'OpenGL ES, y compris les shaders, les textures et les techniques de rendu de base.

### 💡 Lumière & Post-Traitement
Apprenez les modèles d'éclairage, le mapping d'ombres et les effets avancés de post-traitement.

### ✨ Rendu Physique (PBR)
Maîtrisez les concepts PBR pour un rendu réaliste des matériaux.

### 🎨 Techniques Avancées
Explorez les techniques de rendu avancées pour des graphismes de qualité professionnelle.

## 🔧 Exigences

- Android Studio 4.0+
- Android SDK 26+
- Appareil compatible OpenGL ES 3.0+
