# Bienvenue sur LearnGLES

LearnGLES est une application Android qui démontre diverses techniques **OpenGL ES 3.0+**, du rendu de base au rendu physique avancé (PBR) et aux effets de post-traitement.

## 🎯 Ce que vous apprendrez

Cette série de tutoriels couvre tout ce dont vous avez besoin pour devenir expert en programmation graphique mobile :

- **Techniques de Base** : Shaders, textures, transformations et fondamentaux du rendu
- **Lumière** : Modèles Phong/Blinn-Phong, ombres, HDR et post-traitement
- **PBR** : Rendu physique avec IBL, mapping normal/parallaxe
- **Avancé** : CSM, OIT, DSA et autres techniques modernes

## 🛠️ Stack Technique

- **Plateforme** : Android
- **Langage** : Kotlin (UI), C++ (Rendu)
- **Framework UI** : Jetpack Compose
- **API Graphique** : OpenGL ES 3.0+
- **Bibliothèques Clés** : Assimp, GLM, stb_image, FreeType

## 📚 Commencer

1. Cloner le dépôt : `git clone https://github.com/minininja/LearnGLES.git`
2. Ouvrir le projet dans Android Studio (Ladybug ou plus récent)
3. Assurer que NDK et CMake sont installés
4. Construire et exécuter sur un appareil ou émulateur avec support GLES 3.0

## 📖 Structure du Tutoriel

Chaque tutoriel inclut :

- **Explication du Concept** : Ce qu'est la technique et pourquoi elle est importante
- **Fondement Mathématique** : Formules clés et théorie
- **Parcours du Code** : Implémentation étape par étape
- **Démo Interactive** : Essayer dans l'application
