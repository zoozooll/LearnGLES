# Techniques de Base

Les tutoriels de Techniques de Base couvrent les concepts fondamentaux que vous devez comprendre avant de vous aventurer dans des sujets plus avancés.

## 📋 Prérequis

Avant de commencer ces tutoriels, vous devriez avoir:

- Connaissances de base en C++ et Kotlin
- Compréhension de l'algèbre linéaire (vecteurs, matrices)
- Familiarité avec le développement Android

## 🎯 Objectifs d'Apprentissage

Après avoir complété ces tutoriels, vous serez en mesure de:

- Écrire et compiler des shaders GLSL
- Charger et appliquer des textures à des modèles 3D
- Implémenter des transformations de base (translation, rotation, mise à l'échelle)
- Gérer la transparence et le test de profondeur
- Charger des modèles 3D complexes à l'aide d'Assimp
- Implémenter une animation squelettique
