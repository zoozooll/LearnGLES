# Techniques PBR

Les tutoriels de Rendu Physique (PBR) couvrent des techniques avancées de rendu utilisées aujourd'hui dans les jeux et les films.

## 🎯 Objectifs d'Apprentissage

- Comprendre les principes du rendu physique
- Implémenter l'éclairage basé sur les images (IBL)
- Contrôler les propriétés du matériau avec des cartes
- Implémenter le mappage de parallaxe et de déplacement
- Implémenter l'occlusion ambiante

## 📚 Liste des Tutoriels

| Tutoriel | Description |
|----------|-------------|
| [Normal Mapping](/docs/pbr/normal-mapping) | Ajouter des détails de surface sans plus de polygones |
| [Parallax Mapping](/docs/pbr/parallax-mapping) | Simuler la profondeur dans les textures |
| [PBR Theory](/docs/pbr/pbr-theory) | Implémentation Cook-Torrance BRDF |
| [PBR Textures](/docs/pbr/pbr-textures) | Utiliser des cartes de texture PBR |
| [IBL](/docs/pbr/ibl) | Éclairage basé sur les images avec cartes HDR |
