# उन्नत तकनीकें

उन्नत तकनीकों के ट्यूटोरियल मोबाइल प्लेटफार्मों के लिए उन्नत रेंडरिंग तकनीकों को कवर करते हैं।

## 🎯 शिक्षा के लक्ष्य

- कैस्केडेड शैडो मैप्स (CSM) लागू करना
- पारदर्शी ऑब्जेक्ट्स का सही रेंडरिंग (OIT) संभालना
- डायरेक्ट स्टेट एक्सेस (DSA) का उपयोग करना
- डिफर्ड शेडिंग लागू करना
- मोबाइल रेंडरिंग प्रदर्शन को अनुकूलित करना

## 📚 ट्यूटोरियल सूची

| ट्यूटोरियल | विवरण |
|----------|-------------|
| [CSM](/docs/advanced/csm) | उच्च गुणवत्ता वाले शैडो के लिए कैस्केडेड शैडो मैप्स |
| [OIT](/docs/advanced/oit) | ऑर्डर इंडिपेंडेंट ट्रांसपेरेंसी |
| [DSA](/docs/advanced/dsa) | डायरेक्ट स्टेट एक्सेस |
