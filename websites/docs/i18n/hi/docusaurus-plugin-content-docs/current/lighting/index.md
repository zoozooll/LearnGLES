# लाइटिंग तकनीकें

लाइटिंग ट्यूटोरियल वास्तविक लाइट और शैडो प्रभावों को लागू करने के लिए आवश्यक तकनीकों को कवर करते हैं।

## 🎯 शिक्षा के लक्ष्य

- Phong और Blinn-Phong लाइटिंग मॉडल लागू करना
- कई प्रकाश स्रोतों का संचालन करना
- नरम और कठोर छायाएं लागू करना
- HDR रेंडरिंग और एक्सपोजर कंट्रोल लागू करना
- पोस्ट-प्रोसेसिंग प्रभाव लागू करना
