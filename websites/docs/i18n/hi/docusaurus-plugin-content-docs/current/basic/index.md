# बुनियादी तकनीकें

बुनियादी तकनीकों के ट्यूटोरियल उन मूलभूत अवधारणाओं को कवर करते हैं जिन्हें आपको उन्नत विषयों में जाने से पहले समझना चाहिए।

## 📋 पूर्वापेक्षाएं

इन ट्यूटोरियलों को शुरू करने से पहले, आपके पास होना चाहिए:

- C++ और Kotlin का मूल ज्ञान
- रैखिक बीजगणित (वेक्टर, मैट्रिसेस) की समझ
- Android विकास से परिचितता

## 🎯 शिक्षा के लक्ष्य

इन ट्यूटोरियलों को पूरा करने के बाद, आप कर पाएंगे:

- GLSL शेडर्स लिखना और कॉम्पाइल करना
- 3D मॉडलों में टेक्सचर्स लोड करना और लागू करना
- बुनियादी ट्रांसफॉर्मेशन लागू करना (ट्रांसलेशन, रोटेशन, स्केलिंग)
- पारदर्शिता और गहराई परीक्षण संभालना
- Assimp का उपयोग करके जटिल 3D मॉडल लोड करना
- कंकाल एनीमेशन लागू करना
