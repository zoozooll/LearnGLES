# PBR तकनीकें

फिजिकली बेस्ड रेंडरिंग (PBR) ट्यूटोरियल आजकल खेलों और फिल्मों में उपयोग की जाने वाली उन्नत रेंडरिंग तकनीकों को कवर करते हैं।

## 🎯 शिक्षा के लक्ष्य

- भौतिक आधारित रेंडरिंग के सिद्धांतों को समझना
- इमेज-बेस्ड लाइटिंग (IBL) लागू करना
- टेक्सचर्स के साथ सामग्री गुणों को नियंत्रित करना
- पैरालैक्स और डिस्प्लेसमेंट मैपिंग लागू करना
- एम्बिएंट ओक्लूजन लागू करना

## 📚 ट्यूटोरियल सूची

| ट्यूटोरियल | विवरण |
|----------|-------------|
| [Normal Mapping](/docs/pbr/normal-mapping) | अधिक पॉलीगन्स किए बिना सतह विवरण जोड़ना |
| [Parallax Mapping](/docs/pbr/parallax-mapping) | टेक्सचर्स में गहराई का सिमुलेशन करना |
| [PBR Theory](/docs/pbr/pbr-theory) | Cook-Torrance BRDF कार्यान्वयन |
| [PBR Textures](/docs/pbr/pbr-textures) | PBR टेक्सचर मैप्स का उपयोग करना |
| [IBL](/docs/pbr/ibl) | HDR मैप्स के साथ इमेज-बेस्ड लाइटिंग |
