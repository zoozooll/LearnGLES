# Android के लिए OpenGL ES 3.0+ सीखें

LearnGLES में आपका स्वागत है! यह OpenGL ES 3.0+ को Android पर सीखने के लिए एक व्यापक ट्यूटोरियल सीरीज़ है, जो मूल बातों से लेकर उन्नत रेंडरिंग तकनीकों तक कवर करती है।

## 🎯 आप क्या सीखेंगे

- **बुनियादी तकनीकें**: शेडर्स, टेक्सचर्स, ट्रांसफॉर्मेशन और OpenGL के मूल सिद्धांत
- **लाइटिंग और पोस्ट-प्रोसेसिंग**: फोंग लाइटिंग, शैडो मैपिंग, HDR, ब्लूम और SSAO
- **भौतिक आधारित रेंडरिंग**: PBR सिद्धांत, सामग्री गुण और इमेज-आधारित लाइटिंग
- **उन्नत तकनीकें**: कैस्केडेड शैडो मैप्स, ऑर्डर-इंडिपेंडेंट ट्रांसपेरेंसी और डायरेक्ट स्टेट एक्सेस

## 🚀 शुरुआत

1. [GitHub](https://github.com/minininja/LearnGLES) से रिपॉजिटरी क्लोन करें
2. Android Studio में प्रोजेक्ट खोलें
3. Android डिवाइस या एमुलेटर पर बनाएं और चलाएं
4. ट्यूटोरियल को क्रमानुसार देखें: बुनियादी तकनीकें → उन्नत

## 📚 ट्यूटोरियल संरचना

ट्यूटोरियल एक तार्किक प्रगति में व्यवस्थित हैं:

### 🏗️ बुनियादी तकनीकें
OpenGL ES के मूल बातों से शुरुआत करें, जिसमें शेडर्स, टेक्सचर्स और बुनियादी रेंडरिंग तकनीकें शामिल हैं।

### 💡 लाइटिंग और पोस्ट-प्रोसेसिंग
लाइटिंग मॉडल्स, शैडो मैपिंग और उन्नत पोस्ट-प्रोसेसिंग इफ़ेक्ट्स के बारे में जानें।

### ✨ भौतिक आधारित रेंडरिंग
वास्तविक सामग्री रेंडरिंग के लिए PBR सिद्धांतों को मास्टर करें।

### 🎨 उन्नत तकनीकें
पेशेवर गुणवत्ता के ग्राफिक्स के लिए उन्नत रेंडरिंग तकनीकों का पता लगाएं।

## 🔧 आवश्यकताएं

- Android Studio 4.0+
- Android SDK 26+
- OpenGL ES 3.0+ संगत डिवाइस
