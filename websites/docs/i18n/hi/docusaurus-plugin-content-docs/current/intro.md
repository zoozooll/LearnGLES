# LearnGLES में आपका स्वागत है

LearnGLES एक Android ऐप्लिकेशन है जो विभिन्न **OpenGL ES 3.0+** तकनीकों को प्रदर्शित करता है, मूल रेंडरिंग से लेकर उन्नत भौतिक आधारित रेंडरिंग (PBR) और पोस्ट-प्रोसेसिंग इफ़ेक्ट्स तक।

## 🎯 आप क्या सीखेंगे

यह ट्यूटोरियल सीरीज़ मोबाइल ग्राफिक्स प्रोग्रामिंग में प्रो बनने के लिए आपको जो कुछ भी जानने की जरूरत है, वह कवर करती है:

- **बुनियादी तकनीकें**: शेडर्स, टेक्सचर्स, ट्रांसफॉर्मेशन और रेंडरिंग के मूल सिद्धांत
- **लाइटिंग**: Phong/Blinn-Phong मॉडल्स, शैडोव, HDR और पोस्ट-प्रोसेसिंग
- **PBR**: IBL, नॉर्मल/पैरालैक्स मैपिंग के साथ भौतिक आधारित रेंडरिंग
- **उन्नत**: CSM, OIT, DSA और अन्य आधुनिक तकनीकें

## 🛠️ तकनीकी स्टैक

- **प्लेटफॉर्म**: Android
- **भाषा**: Kotlin (UI), C++ (रेंडरिंग)
- **UI फ्रेमवर्क**: Jetpack Compose
- **ग्राफिक्स API**: OpenGL ES 3.0+
- **प्रमुख लाइब्रेरियां**: Assimp, GLM, stb_image, FreeType

## 📚 शुरुआत

1. रिपॉजिटरी क्लोन करें: `git clone https://github.com/minininja/LearnGLES.git`
2. Android Studio (Ladybug या नया) में प्रोजेक्ट खोलें
3. सुनिश्चित करें कि NDK और CMake इंस्टॉल हैं
4. GLES 3.0 समर्थन वाले डिवाइस या एमुलेटर पर बनाएं और चलाएं

## 📖 ट्यूटोरियल संरचना

प्रत्येक ट्यूटोरियल में शामिल हैं:

- **संकल्पना की व्याख्या**: तकनीक क्या है और यह क्यों महत्वपूर्ण है
- **गणितीय पृष्ठभूमि**: प्रमुख सूत्र और सिद्धांत
- **कोड वॉकथ्रू**: चरण-दर-चरण कार्यान्वयन
- **इंटरैक्टिव डेमो**: ऐप में आज़माएं
