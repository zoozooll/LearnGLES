# Selamat Datang di LearnGLES

LearnGLES adalah aplikasi Android yang mendemonstrasikan berbagai teknik **OpenGL ES 3.0+**, dari rendering dasar hingga rendering berbasis fisika (PBR) dan efek pemrosesan akhir.

## 🎯 Apa yang Anda Pelajari

Seri tutorial ini mencakup semua yang Anda butuhkan untuk menjadi ahli dalam pemrograman grafis seluler:

- **Teknik Dasar**: Shader, tekstur, transformasi, dan dasar-dasar rendering
- **Pencahayaan**: Model Phong/Blinn-Phong, bayangan, HDR, dan pemrosesan akhir
- **PBR**: Rendering berbasis fisika dengan IBL, pemetaan normal/parallax
- **Lanjutan**: CSM, OIT, DSA, dan teknik modern lainnya

## 🛠️ Teknologi yang Digunakan

- **Platform**: Android
- **Bahasa**: Kotlin (UI), C++ (Rendering)
- **Framework UI**: Jetpack Compose
- **API Grafis**: OpenGL ES 3.0+
- **Pustaka Kunci**: Assimp, GLM, stb_image, FreeType

## 📚 Memulai

1. Klon repositori: `git clone https://github.com/minininja/LearnGLES.git`
2. Buka proyek di Android Studio (Ladybug atau yang lebih baru)
3. Pastikan NDK dan CMake terinstal
4. Bangun dan jalankan di perangkat atau emulator dengan dukungan GLES 3.0

## 📖 Struktur Tutorial

Setiap tutorial mencakup:

- **Penjelasan Konsep**: Apa tekniknya dan mengapa penting
- **Latar Belakang Matematis**: Rumus kunci dan teori
- **Walkthrough Kode**: Implementasi langkah demi langkah
- **Demo Interaktif**: Coba di aplikasi
