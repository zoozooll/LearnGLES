# Teknik Dasar

Tutorial Teknik Dasar mencakup konsep fundamental yang Anda butuhkan untuk memahami sebelum mempelajari topik yang lebih lanjut.

## 📋 Prasyarat

Sebelum memulai tutorial ini, Anda seharusnya memiliki:

- Pengetahuan dasar C++ dan Kotlin
- Pemahaman aljabar linear (vektor, matriks)
- Keakraban dengan pengembangan Android

## 🎯 Tujuan Pembelajaran

Setelah menyelesaikan tutorial ini, Anda akan dapat:

- Menulis dan mengompilasi shader GLSL
- Memuat dan menerapkan tekstur ke model 3D
- Mengimplementasikan transformasi dasar (translasi, rotasi, penskalaan)
- Menangani transparansi dan pengujian kedalaman
- Memuat model 3D kompleks menggunakan Assimp
- Mengimplementasikan animasi kerangka
