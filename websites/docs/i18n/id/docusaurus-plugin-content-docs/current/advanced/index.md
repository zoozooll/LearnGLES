# Teknik Lanjutan

Tutorial Teknik Lanjutan mencakup teknik rendering canggih untuk platform mobile.

## 🎯 Tujuan Pembelajaran

- Mengimplementasikan peta bayangan bertingkat (CSM)
- Mengelola rendering objek transparan yang benar (OIT)
- Menggunakan akses status langsung (DSA)
- Mengimplementasikan shading diferred
- Mengoptimalkan kinerja rendering mobile

## 📚 Daftar Tutorial

| Tutorial | Deskripsi |
|----------|-------------|
| [CSM](/docs/advanced/csm) | Peta bayangan bertingkat untuk bayangan berkualitas tinggi |
| [OIT](/docs/advanced/oit) | Transparansi independen urutan |
| [DSA](/docs/advanced/dsa) | Akses status langsung |
