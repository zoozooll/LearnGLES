# Pelajari OpenGL ES 3.0+ untuk Android

Selamat datang di LearnGLES! Ini adalah seri tutorial komprehensif untuk mempelajari OpenGL ES 3.0+ di Android, mencakup konsep dasar hingga teknik rendering lanjutan.

## 🎯 Apa yang Anda Pelajari

- **Teknik Dasar**: Shader, tekstur, transformasi, dan konsep OpenGL fundamental
- **Pencahayaan & Pemrosesan Akhir**: Pencahayaan Phong, pemetaan bayangan, HDR, bloom, dan SSAO
- **Rendering Berbasis Fisika**: Teori PBR, properti material, dan pencahayaan berbasis gambar
- **Teknik Lanjutan**: Peta bayangan bertingkat, transparansi independen urutan, dan akses status langsung

## 🚀 Memulai

1. Klon repositori dari [GitHub](https://github.com/minininja/LearnGLES)
2. Buka proyek di Android Studio
3. Bangun dan jalankan di perangkat atau emulator Android
4. Ikuti tutorial secara berurutan: Teknik Dasar → Lanjutan

## 📚 Struktur Tutorial

Tutorial diatur dalam progresi logis:

### 🏗️ Teknik Dasar
Mulai dengan dasar-dasar OpenGL ES, termasuk shader, tekstur, dan teknik rendering dasar.

### 💡 Pencahayaan & Pemrosesan Akhir
Pelajari model pencahayaan, pemetaan bayangan, dan efek pemrosesan akhir lanjutan.

### ✨ Rendering Berbasis Fisika
Kuasi konsep PBR untuk rendering material realistis.

### 🎨 Teknik Lanjutan
Jelajahi teknik rendering lanjutan untuk grafis berkualitas profesional.

## 🔧 Persyaratan

- Android Studio 4.0+
- Android SDK 26+
- Perangkat kompatibel OpenGL ES 3.0+
