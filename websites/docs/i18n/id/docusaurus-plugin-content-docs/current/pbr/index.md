# Teknik PBR

Tutorial Rendering Berbasis Fisika (PBR) mencakup teknik rendering canggih yang digunakan dalam game dan film saat ini.

## 🎯 Tujuan Pembelajaran

- Memahami prinsip rendering berbasis fisika
- Mengimplementasikan pencahayaan berbasis gambar (IBL)
- Mengontrol properti material dengan peta
- Mengimplementasikan pemetaan paralaks dan perpindahan
- Mengimplementasikan oklusi ambient
