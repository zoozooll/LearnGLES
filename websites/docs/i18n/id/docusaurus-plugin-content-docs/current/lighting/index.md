# Teknik Pencahayaan

Tutorial Pencahayaan mencakup teknik esensial untuk mengimplementasikan efek cahaya dan bayangan yang realistis.

## 🎯 Tujuan Pembelajaran

- Mengimplementasikan model pencahayaan Phong dan Blinn-Phong
- Mengelola beberapa sumber cahaya
- Mengimplementasikan bayangan lembut dan keras
- Mengimplementasikan rendering HDR dan kontrol eksposur
- Menerapkan efek pemrosesan akhir
