# 照明技術

照明のチュートリアルは、リアルな光と影の効果を実装するための必須技術をカバーしています。

## 🎯 学習目標

- PhongおよびBlinn-Phong照明モデルの実装
- 複数の光源の処理
- ソフトシャドウとハードシャドウの実装
- HDRレンダリングと露出制御の実装
- ポストプロセス効果の適用
