# PBR技術

物理ベースレンダリング（PBR）のチュートリアルは、現在のゲームや映画で使用されている高度なレンダリング技術をカバーしています。

## 🎯 学習目標

- 物理ベースレンダリングの原理を理解
- 画像ベース照明（IBL）の実装
- テクスチャを使用したマテリアルプロパティの制御
- パララックスとディスプレイスメントマッピングの実装
- 環境オクルージョンの実装

## 📚 チュートリアルリスト

| チュートリアル | 説明 |
|----------|-------------|
| [Normal Mapping](/docs/pbr/normal-mapping) | ポリゴンを増やさずに表面の詳細を追加 |
| [Parallax Mapping](/docs/pbr/parallax-mapping) | テクスチャの深さをシミュレート |
| [PBR Theory](/docs/pbr/pbr-theory) | Cook-Torrance BRDFの実装 |
| [PBR Textures](/docs/pbr/pbr-textures) | PBRテクスチャマップの使用 |
| [IBL](/docs/pbr/ibl) | HDRマップを使用した画像ベース照明 |
