# Android の OpenGL ES 3.0+ を学ぶ

LearnGLESへようこそ！これはAndroid上でOpenGL ES 3.0+を学ぶための包括的なチュートリアルシリーズであり、基礎概念から高度なレンダリング技術までカバーしています。

## 🎯 学べること

- **基本技術**: シェーダー、テクスチャ、変換、およびOpenGLの基本概念
- **照明とポストプロセッシング**: Phong照明、シャドウマッピング、HDR、ブルーム、およびSSAO
- **物理ベースレンダリング**: PBR理論、マテリアルプロパティ、およびイメージベース照明
- **高度な技術**: カスケードシャドウマップ、順序独立透明性、およびダイレクトステートアクセス

## 🚀 はじめに

1. [GitHub](https://github.com/minininja/LearnGLES) からリポジトリをクローン
2. Android Studio でプロジェクトを開く
3. Android デバイスまたはエミュレータでビルドして実行
4. チュートリアルを順番にフォロー: 基本技術 → 高度な技術

## 📚 チュートリアル構造

チュートリアルは論理的な進行順に組織されています:

### 🏗️ 基本技術
OpenGL ESの基礎から始めます。シェーダー、テクスチャ、および基本的なレンダリング技術を含みます。

### 💡 照明とポストプロセッシング
照明モデル、シャドウマッピング、および高度なポストプロセッシング効果について学びます。

### ✨ 物理ベースレンダリング
リアルなマテリアルレンダリングのためのPBR概念をマスターします。

### 🎨 高度な技術
プロフェッショナル品質のグラフィックスのための高度なレンダリング技術を探求します。

## 🔧 必要条件

- Android Studio 4.0+
- Android SDK 26+
- OpenGL ES 3.0+ 対応デバイス
