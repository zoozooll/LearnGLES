# 基本技術

基本技術のチュートリアルは、より高度なトピックに進む前に理解する必要のある基本的な概念をカバーしています。

## 📋 前提条件

これらのチュートリアルを開始する前に、以下が必要です。

- C++とKotlinの基礎知識
- 線形代数（ベクトル、行列）の理解
- Android開発への精通

## 🎯 学習目標

これらのチュートリアルを完了すると、以下ができるようになります。

- GLSLシェーダーの記述とコンパイル
- 3Dモデルへのテクスチャの読み込みと適用
- 基本的な変換の実装（平行移動、回転、スケーリング）
- 透明度と深度テストの処理
- Assimpを使用した複雑な3Dモデルの読み込み
- スケルタルアニメーションの実装
