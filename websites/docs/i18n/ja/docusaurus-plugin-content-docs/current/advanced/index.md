# 高度な技術

高度な技術のチュートリアルは、モバイルプラットフォーム向けの高度なレンダリング技術をカバーしています。

## 🎯 学習目標

- カスケードシャドウマップ（CSM）の実装
- 透明オブジェクトの正しいレンダリング（OIT）の処理
- ダイレクトステートアクセス（DSA）の使用
- ディファードシェーディングの実装
- モバイルレンダリングパフォーマンスの最適化
