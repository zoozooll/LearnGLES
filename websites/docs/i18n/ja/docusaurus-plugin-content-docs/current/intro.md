# LearnGLESへようこそ

LearnGLESは、基本的なレンダリングから高度な物理ベースレンダリング(PBR)およびポストプロセッシング効果まで、さまざまな**OpenGL ES 3.0+**技術を実演するAndroidアプリケーションです。

## 🎯 学べること

このチュートリアルシリーズは、モバイルグラフィックスプログラミングのプロになるために必要なすべてをカバーしています。

- **基本技術**: シェーダー、テクスチャ、変換、およびレンダリングの基礎
- **照明**: Phong/Blinn-Phongモデル、シャドウ、HDR、およびポストプロセッシング
- **PBR**: IBL、法線/視差マッピングを使用した物理ベースレンダリング
- **高度**: CSM、OIT、DSA、およびその他の最新技術

## 🛠️ 技術スタック

- **プラットフォーム**: Android
- **言語**: Kotlin (UI)、C++ (レンダリング)
- **UIフレームワーク**: Jetpack Compose
- **グラフィックスAPI**: OpenGL ES 3.0+
- **主要ライブラリ**: Assimp、GLM、stb_image、FreeType

## 📚 はじめに

1. リポジトリをクローン: `git clone https://github.com/minininja/LearnGLES.git`
2. Android Studio (Ladybug以降)でプロジェクトを開く
3. NDKとCMakeがインストールされていることを確認する
4. GLES 3.0をサポートするデバイスまたはエミュレータでビルドして実行する

## 📖 チュートリアル構造

各チュートリアルには以下が含まれています。

- **概念の説明**: 技術が何であるか、およびそれが重要である理由
- **数学的背景**: 重要な公式と理論
- **コードの解説**: 段階的な実装
- **インタラクティブなデモ**: アプリで試す
