# PBR 技術

物理基於渲染（PBR）教程涵蓋了當今遊戲和電影中使用的先進渲染技術。

## 🎯 學習目標

- 理解基於物理的渲染原理
- 實現基於圖像的光照（IBL）
- 使用貼圖控制材質屬性
- 實現視差和位移映射
- 實現環境遮蔽

## 📚 教程列表

| 教程 | 描述 |

| [Normal Mapping](/docs/pbr/normal-mapping) | 無需更多多邊形即可添加表面細節 |
| [Parallax Mapping](/docs/pbr/parallax-mapping) | 模擬紋理深度 |
