# 歡迎來到 LearnGLES

LearnGLES 是一個 Android 應用程式，展示了各種 **OpenGL ES 3.0+** 技術，從基本渲染到高級基於物理的渲染 (PBR) 和後處理效果。

## 🎯 你將學到什麼

本教程系列涵蓋了你成為移動圖形編程專家所需了解的一切：

- **基礎技術**：著色器、紋理、變換和渲染基礎
- **光照**：Phong/Blinn-Phong 模型、陰影、HDR 和後處理
- **PBR**：基於物理的渲染，包括 IBL、法線/視差貼圖
- **高級**：CSM、OIT、DSA 和其他現代技術

## 🛠️ 技術堆疊

- **平台**：Android
- **語言**：Kotlin (UI)、C++ (渲染)
- **UI 框架**：Jetpack Compose
- **圖形 API**：OpenGL ES 3.0+
- **關鍵庫**：Assimp、GLM、stb_image、FreeType

## 📚 開始學習

1. 克隆倉庫：`git clone https://github.com/minininja/LearnGLES.git`
2. 在 Android Studio (Ladybug 或更新版本) 中打開項目
3. 確保安裝了 NDK 和 CMake
4. 在支援 GLES 3.0 的設備或模擬器上構建並運行

## 📖 教程結構

每個教程包括：

- **概念解釋**：技術是什麼以及為什麼重要
- **數學背景**：關鍵公式和理論
- **代碼演練**：分步實現
- **交互式演示**：在應用中嘗試
