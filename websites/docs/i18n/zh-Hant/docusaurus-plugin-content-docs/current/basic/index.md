# 基礎技術

基礎技術教程涵蓋了你在深入更高級主題之前需要理解的基本概念。

## 📋 前提條件

開始這些教程之前，你應該具備：

- C++ 和 Kotlin 的基礎知識
- 線性代數（向量、矩陣）的理解
- Android 開發的熟悉度

## 🎯 學習目標

完成這些教程後，你將能夠：

- 編寫和編譯 GLSL 著色器
- 載入並套用紋理到 3D 模型
- 實現基本變換（平移、旋轉、縮放）
- 處理透明度和深度測試
- 使用 Assimp 載入複雜的 3D 模型
- 實現骨骼動畫
