# 學習 Android 平台的 OpenGL ES 3.0+

歡迎來到 LearnGLES！這是一套全面的 OpenGL ES 3.0+ Android 教程系列，涵蓋從基礎概念到高級渲染技術。

## 🎯 你將學到什麼

- **基礎技術**：著色器、紋理、變換和 OpenGL 基本概念
- **光照與後處理**：Phong 光照、陰影映射、HDR、Bloom 和 SSAO
- **基於物理的渲染**：PBR 理論、材質屬性和基於圖像的光照
- **高級技術**：級聯陰影貼圖、順序無關透明度和直接狀態訪問

## 🚀 開始學習

1. 從 [GitHub](https://github.com/minininja/LearnGLES) 克隆倉庫
2. 在 Android Studio 中打開項目
3. 在 Android 設備或模擬器上構建並運行
4. 按順序學習教程：基礎技術 → 高級技術

## 📚 教程結構

教程按照邏輯順序組織：

### 🏗️ 基礎技術
從 OpenGL ES 的基礎知識開始，包括著色器、紋理和基本渲染技術。

### 💡 光照與後處理
學習光照模型、陰影映射和高級後處理效果。

### ✨ 基於物理的渲染
掌握 PBR 概念，實現逼真的材質渲染。

### 🎨 高級技術
探索專業級圖形的高級渲染技術。

## 🔧 系統要求

- Android Studio 4.0+
- Android SDK 26+
- 支持 OpenGL ES 3.0+ 的設備
