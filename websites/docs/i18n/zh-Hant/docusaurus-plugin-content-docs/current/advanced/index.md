# 高級技術

高級技術教程涵蓋了移動平台上的先進渲染技術。

## 🎯 學習目標

- 實現分級陰影圖（CSM）
- 處理透明物體的正確渲染（OIT）
- 使用直接狀態訪問（DSA）
- 實現延遲渲染
- 優化移動渲染性能

| 教程 | 描述 |
|------|------|

| [DSA](/docs/advanced/dsa) | 直接狀態訪問 |
