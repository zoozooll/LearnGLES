# 照明技術

照明教程涵蓋了實現逼真光影效果的核心技術。

## 🎯 學習目標

- 實現 Phong 和 Blinn-Phong 光照模型
- 處理多重光源
- 實現軟陰影和硬陰影
- 實現 HDR 渲染和曝光控制
- 應用後處理效果
