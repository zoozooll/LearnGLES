# Основные Техники

Туториалы Основных Техник охватывают фундаментальные концепты, которые вам нужно понять, прежде чем перейти к более сложным темам.

## 📋 Предварительные Требования

Перед началом этих туториалов у вас должно быть:

- Базовые знания C++ и Kotlin
- Понимание линейной алгебры (векторы, матрицы)
- Знакомство с разработкой Android

## 🎯 Учебные Цели

После завершения этих туториалов вы сможете:

- Написывать и компилировать шейдеры GLSL
- Загружать и применять текстуры к 3D-моделям
- Реализовывать базовые преобразования (трансляция, вращение, масштабирование)
- Обрабатывать прозрачность и тест глубины
- Загружать сложные 3D-модели с помощью Assimp
- Реализовывать скелетную анимацию
