# Техники Освещения

Туториалы по Освещению охватывают основные техники для реализации реалистичных эффектов света и теней.

## 🎯 Учебные Цели

- Реализовать модели освещения Phong и Blinn-Phong
- Обрабатывать несколько источников света
- Реализовать мягкие и твердые тени
- Реализовать HDR-рендеринг и контроль экспозиции
- Применять эффекты пост-обработки
