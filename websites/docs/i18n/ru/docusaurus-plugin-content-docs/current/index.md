# Изучение OpenGL ES 3.0+ для Android

Добро пожаловать в LearnGLES! Это полноценная серия туториалов по изучению OpenGL ES 3.0+ на Android, охватывающая основные концепции и продвинутые техники рендеринга.

## 🎯 Что вы узнаете

- **Основные Техники**: Шейдеры, текстуры, трансформации и основные концепции OpenGL
- **Освещение и Пост-обработка**: Освещение Фонга, тени, HDR, Bloom и SSAO
- **Физически Основанный Рендеринг**: Теория PBR, свойства материалов и изображение-ориентированное освещение
- **Продвинутые Техники**: Каскадные карты теней, прозрачность, не зависящая от порядка, и прямой доступ к состоянию

## 🚀 Начало

1. Клонируйте репозиторий с [GitHub](https://github.com/minininja/LearnGLES)
2. Откройте проект в Android Studio
3. Соберите и запустите на устройстве или эмуляторе Android
4. Следуйте туториалам в порядке: Основные Техники → Продвинутые

## 📚 Структура Туториалов

Туториалы организованы по логической последовательности:

### 🏗️ Основные Техники
Начните с основ OpenGL ES, включая шейдеры, текстуры и базовые техники рендеринга.

### 💡 Освещение и Пост-обработка
Изучите модели освещения, отображение теней и продвинутые эффекты пост-обработки.

### ✨ Физически Основанный Рендеринг
Освойте концепции PBR для реалистичного рендеринга материалов.

### 🎨 Продвинутые Техники
Исследуйте продвинутые техники рендеринга для профессиональной графики.

## 🔧 Требования

- Android Studio 4.0+
- Android SDK 26+
- Устройство, поддерживающее OpenGL ES 3.0+
