# Продвинутые Техники

Туториалы Продвинутых Техник охватывают передовые техники рендеринга для мобильных платформ.

## 🎯 Учебные Цели

- Реализовать каскадные карты теней (CSM)
- Обрабатывать правильный рендеринг прозрачных объектов (OIT)
- Использовать прямой доступ к состоянию (DSA)
- Реализовать отложенное затенение
- Оптимизировать производительность мобильного рендеринга

## 📚 Список Туториалов

| Туториал | Описание |
|----------|-------------|
| [CSM](/docs/advanced/csm) | Каскадные карты теней для теней высокого качества |
| [OIT](/docs/advanced/oit) | Порядочно-независимая прозрачность |
| [DSA](/docs/advanced/dsa) | Прямой доступ к состоянию |
