# PBR-Техники

Туториалы по Физически Основанному Рендерингу (PBR) охватывают передовые техники рендеринга, используемые сегодня в играх и фильмах.

## 🎯 Учебные Цели

- Понять принципы физически основанного рендеринга
- Реализовать изображение-ориентированное освещение (IBL)
- Управлять свойствами материала с помощью карт
- Реализовать параллакс- и дисплейсмент-мэппинг
- Реализовать окружностную окклюзию

## 📚 Список Туториалов

| Туториал | Описание |
|----------|-------------|
| [Normal Mapping](/docs/pbr/normal-mapping) | Добавление деталей поверхности без увеличения полигонов |
| [Parallax Mapping](/docs/pbr/parallax-mapping) | Симуляция глубины в текстурах |
| [PBR Theory](/docs/pbr/pbr-theory) | Реализация Cook-Torrance BRDF |
| [PBR Textures](/docs/pbr/pbr-textures) | Использование PBR-текстурных карт |
| [IBL](/docs/pbr/ibl) | Изображение-ориентированное освещение с HDR-картами |
