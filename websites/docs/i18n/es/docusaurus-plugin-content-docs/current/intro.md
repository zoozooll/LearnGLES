# ¡Bienvenido a LearnGLES!

LearnGLES es una aplicación Android que demuestra diversas técnicas **OpenGL ES 3.0+**, desde el renderizado básico hasta el renderizado físico avanzado (PBR) y efectos de post-procesamiento.

## 🎯 Lo que aprenderás

Esta serie de tutoriales cubre todo lo que necesitas saber para convertirte en un experto en programación de gráficos móviles:

- **Técnicas Básicas**: Shaders, texturas, transformaciones y fundamentos del renderizado
- **Iluminación**: Modelos Phong/Blinn-Phong, sombras, HDR y post-procesamiento
- **PBR**: Renderizado basado en física con IBL, mapeo normal/parallax
- **Avanzado**: CSM, OIT, DSA y otras técnicas modernas

## 🛠️ Pila de Tecnologías

- **Plataforma**: Android
- **Lenguaje**: Kotlin (UI), C++ (Renderizado)
- **Framework UI**: Jetpack Compose
- **API de Gráficos**: OpenGL ES 3.0+
- **Bibliotecas Clave**: Assimp, GLM, stb_image, FreeType

## 📚 Empezar

1. Clonar el repositorio: `git clone https://github.com/minininja/LearnGLES.git`
2. Abrir el proyecto en Android Studio (Ladybug o superior)
3. Asegurarse de tener NDK y CMake instalados
4. Construir y ejecutar en un dispositivo o emulador con soporte GLES 3.0

## 📖 Estructura del Tutorial

Cada tutorial incluye:

- **Explicación del Concepto**: Qué es la técnica y por qué es importante
- **Fondo Matemático**: Fórmulas clave y teoría
- **Recorrido por el Código**: Implementación paso a paso
- **Demo Interactiva**: Prueba la aplicación
