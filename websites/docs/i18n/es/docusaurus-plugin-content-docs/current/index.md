# Aprende OpenGL ES 3.0+ para Android

¡Bienvenido a LearnGLES! Esta es una serie completa de tutoriales para aprender OpenGL ES 3.0+ en Android, que cubre conceptos fundamentales hasta técnicas avanzadas de renderizado.

## 🎯 Lo que aprenderás

- **Técnicas Básicas**: Shaders, texturas, transformaciones y conceptos fundamentales de OpenGL
- **Iluminación y Post-Procesamiento**: Iluminación Phong, mapeo de sombras, HDR, bloom y SSAO
- **Renderizado Basado en Física**: Teoría PBR, propiedades de materiales e iluminación basada en imágenes
- **Técnicas Avanzadas**: Mapas de sombras en cascada, transparencia independiente del orden y acceso directo al estado

## 🚀 Empezar

1. Clona el repositorio desde [GitHub](https://github.com/minininja/LearnGLES)
2. Abre el proyecto en Android Studio
3. Construye y ejecuta en un dispositivo o emulador Android
4. Sigue los tutoriales en orden: Técnicas Básicas → Avanzadas

## 📚 Estructura de Tutoriales

Los tutoriales están organizados en una progresión lógica:

### 🏗️ Técnicas Básicas
Empieza con los fundamentos de OpenGL ES, incluyendo shaders, texturas y técnicas básicas de renderizado.

### 💡 Iluminación y Post-Procesamiento
Aprende sobre modelos de iluminación, mapeo de sombras y efectos avanzados de post-procesamiento.

### ✨ Renderizado Basado en Física
Domina los conceptos PBR para renderizado realista de materiales.

### 🎨 Técnicas Avanzadas
Explora técnicas avanzadas de renderizado para gráficos de calidad profesional.

## 🔧 Requisitos

- Android Studio 4.0+
- Android SDK 26+
- Dispositivo compatible con OpenGL ES 3.0+
