# Técnicas de Iluminación

Los tutoriales de Iluminación cubren las técnicas esenciales para implementar efectos realistas de luz y sombra.

## 🎯 Objetivos de Aprendizaje

- Implementar modelos de iluminación Phong y Blinn-Phong
- Manejar múltiples fuentes de luz
- Implementar sombras suaves y duras
- Implementar renderizado HDR y control de exposición
- Aplicar efectos de post-procesamiento
