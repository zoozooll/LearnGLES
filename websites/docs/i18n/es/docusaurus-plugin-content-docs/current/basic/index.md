# Técnicas Básicas

Los tutoriales de Técnicas Básicas cubren los conceptos fundamentales que necesitas entender antes de profundizar en temas más avanzados.

## 📋 Prerrequisitos

Antes de empezar estos tutoriales, debes tener:

- Conocimientos básicos de C++ y Kotlin
- Entendimiento de álgebra lineal (vectores, matrices)
- Familiaridad con el desarrollo Android

## 🎯 Objetivos de Aprendizaje

Después de completar estos tutoriales, podrás:

- Escribir y compilar shaders GLSL
- Cargar y aplicar texturas a modelos 3D
- Implementar transformaciones básicas (traslación, rotación, escala)
- Manejar transparencia y prueba de profundidad
- Cargar modelos 3D complejos usando Assimp
- Implementar animación esquelética
