# Técnicas Avanzadas

Los tutoriales de Técnicas Avanzadas cubren técnicas de renderizado avanzadas para plataformas móviles.

## 🎯 Objetivos de Aprendizaje

- Implementar mapas de sombra en cascada (CSM)
- Manejar el renderizado correcto de objetos transparentes (OIT)
- Usar acceso directo a estado (DSA)
- Implementar sombreado diferido
- Optimizar el rendimiento del renderizado móvil
