# Basic Techniques

The Basic Techniques tutorials cover the fundamental concepts you need to understand before diving into more advanced topics.

## 📋 Prerequisites

Before starting these tutorials, you should have:

- Basic knowledge of C++ and Kotlin
- Understanding of linear algebra (vectors, matrices)
- Familiarity with Android development

## 🎯 Learning Objectives

After completing these tutorials, you will be able to:

- Write and compile GLSL shaders
- Load and apply textures to 3D models
- Implement basic transformations (translation, rotation, scaling)
- Handle transparency and depth testing
- Load complex 3D models using Assimp
- Implement skeletal animation
