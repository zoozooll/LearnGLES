# Advanced Techniques

The Advanced Techniques tutorials cover cutting-edge rendering techniques that solve complex problems and improve performance.

## 📋 Prerequisites

- All previous tutorials completed
- Strong understanding of OpenGL ES concepts

## 🎯 Learning Objectives

After completing these tutorials, you will be able to:

- Implement cascaded shadow maps for large scenes
- Render transparent objects correctly with OIT
- Use Direct State Access for better performance

|----------|-------------|
| [CSM](/advanced/csm) | Cascaded Shadow Maps for high-quality shadows |
| [OIT](/advanced/oit) | Order Independent Transparency |
| [DSA](/advanced/dsa) | Direct State Access |
