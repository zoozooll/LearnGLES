# Physically Based Rendering

The PBR tutorials cover modern rendering techniques that produce photorealistic results by simulating the physical properties of light and materials.

## 📋 Prerequisites

- Basic Techniques tutorials completed
- Lighting tutorials completed
- Understanding of BRDF and material properties

## 🎯 Learning Objectives

After completing these tutorials, you will be able to:

- Implement the Cook-Torrance BRDF
- Use PBR texture maps (albedo, normal, metallic, roughness, AO)
- Implement image-based lighting (IBL)
- Add surface details with normal and parallax mapping
