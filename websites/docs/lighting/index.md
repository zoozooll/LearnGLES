# Lighting & Post-Processing

The Lighting & Post-Processing tutorials cover techniques to make your 3D scenes look more realistic and visually appealing.

## 📋 Prerequisites

- Basic Techniques tutorials completed
- Understanding of vector math and dot products

## 🎯 Learning Objectives

After completing these tutorials, you will be able to:

- Implement Phong and Blinn-Phong lighting models
- Handle multiple light types (directional, point, spot)
- Generate real-time shadows
- Implement HDR rendering and gamma correction
- Add post-processing effects like bloom and SSAO
