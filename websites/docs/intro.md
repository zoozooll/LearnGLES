# Welcome to LearnGLES

LearnGLES is an Android application demonstrating various **OpenGL ES 3.0+** techniques, from basic rendering to advanced physically based rendering (PBR) and post-processing effects.

## 🎯 What You'll Learn

This tutorial series covers everything you need to know to become proficient in mobile graphics programming:

- **Basic Techniques**: Shaders, textures, transformations, and rendering fundamentals
- **Lighting**: Phong/Blinn-Phong models, shadows, HDR, and post-processing
- **PBR**: Physically based rendering with IBL, normal/parallax mapping
- **Advanced**: CSM, OIT, DSA, and other modern techniques

## 🛠️ Tech Stack

- **Platform**: Android
- **Language**: Kotlin (UI), C++ (Rendering)
- **UI Framework**: Jetpack Compose
- **Graphics API**: OpenGL ES 3.0+
- **Key Libraries**: Assimp, GLM, stb_image, FreeType

## 📚 Getting Started

1. Clone the repository: `git clone https://github.com/minininja/LearnGLES.git`
2. Open the project in Android Studio (Ladybug or newer)
3. Ensure you have the NDK and CMake installed
4. Build and run on a device or emulator with GLES 3.0 support

## 📖 Tutorial Structure

Each tutorial includes:

- **Concept Explanation**: What the technique is and why it matters
- **Mathematical Background**: Key formulas and theory
- **Code Walkthrough**: Step-by-step implementation
- **Interactive Demo**: Try it out in the app
