# LearnGLES

Welcome — this repository contains OpenGL ES tutorials and demo source code for Android. This Docusaurus setup provides a minimal documentation site to browse examples and explanations.

To run locally:

1. Install dependencies: `npm install`
2. Start the dev server: `npm start`

To build the static site: `npm run build`.

Add more docs in the `docs/` directory.
